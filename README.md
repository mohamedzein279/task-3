الـ Class عبارة عن قالب بنعمل منه Object
عني لو عندنا Student، نقدر نعمل Class فيه بيانات الطالب زي الـ ID والاسم والسن. بستخدم ال class لما أحتاج أمثّل عن شئ عنده بيانا مثلا، زي Student أو Course أو Instructo

الـ Struct شبه الـ Class، لأن الاتنين بيحتووا على بيانات وMethods، لكن الفرق بينهم ان class هو Reference Type.
 الـ Class، لما تسند Object لمتغير تاني، الاتنين بيشاوروا على نفس الـ Object
 struct هو Value Type.
